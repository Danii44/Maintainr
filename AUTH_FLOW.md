# Authentication and onboarding flow

Maintainr uses the scaffold’s Manus OAuth session flow for both `/sign-in` and `/sign-up`. The two routes provide distinct user-facing guidance, but both intentionally start the same secure OAuth authorization flow. OAuth callback handling upserts the authenticated identity into the `users` table, creating the account on first login and updating the existing record on subsequent logins.

After authentication, the user’s exact role is checked by the protected portal route guard. Tenants who do not yet have a unit binding use `/join-unit`, enter the six-digit code generated by a property manager, and call the protected onboarding procedure before entering the tenant portal. Role assignment and organization/unit scoping remain server-side concerns; the frontend guard is only an additional navigation layer.

Firebase configuration is intentionally deferred. The blank Firebase setup files document a later migration path without changing the current OAuth/database behavior.
